# PRACTISX

A repository dedicated to coding practice, full-stack experiments, and backend APIs.

## Projects

### 1. `orders-api`
A RESTful Express.js order processing backend with an interactive web UI.
- **Backend**: Express.js with JSON request validation and in-memory order management.
- **Frontend**: Clean glassmorphism UI for creating orders with `productId`, `quantity`, and `customerEmail`.
- **API Endpoints**:
  - `POST /api/orders` - Create an order
  - `GET /api/orders` - Retrieve list of created orders
